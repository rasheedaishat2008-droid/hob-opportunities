Publishing and administration

Internal guidance for managing the directory through the existing HOB Opportunities spreadsheet.

This is not a private admin dashboard. This page is informational and is publicly reachable. Do not place credentials, private records or admin actions here.

Publishing workflow

  1. Review the opportunity and confirm the original provider announcement and application link.
  2. Check current eligibility, funding, required documents and deadline.
  3. Set the spreadsheet's publication status to the exact approved status configured in the publishing endpoint.
  4. Keep drafts, rejected submissions and internal notes out of the public data response.
  5. Recheck or expire listings when deadlines pass or the provider closes the call.

Private administration

For a genuine private admin interface, use authenticated access (for example Cloudflare Access) and server-side permission checks. The public website should never include API keys or rely on hiding admin buttons as security.

Integration status

The website reads approved opportunity data from the URL configured in assets/config.js. The endpoint must filter unpublished rows on the server before launch. The current older Apps Script example returns every row and must not be exposed publicly unchanged.
